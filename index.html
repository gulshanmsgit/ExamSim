Supported formats

Plain text: one question per block. Numbering, option styles (A. A) A: (A)) and answer labels (Answer: Ans: KEY: Correct: Answer Key:) are detected automatically. Subject: and Explanation: lines are optional. Never include option E; the app adds it.

1. Which of the following is a volatile memory?
A. Hard disk
B. RAM
C. ROM
D. SSD
Answer: B
Subject: Computers
Explanation: RAM loses its contents without power.

JSON: an array of objects. id, subject and explanation are optional.

[
  {
    "question": "Question text here",
    "options": { "A": "...", "B": "...", "C": "...", "D": "..." },
    "answer": "B",
    "subject": "Ed. Psychology",
    "explanation": "Optional, shown after submission"
  }
]

PDF: text is extracted in the browser, then parsed as plain text. Scanned PDFs and complex layouts may not parse; use text or JSON for those.
